# Retail Sales Analysis:

## Project Overview:-
This project focuses on analysing retail sales data to identify sales trends, product performance, and business insights using data analytics tools.

## Tools & Technologies:-
- Python (Pandas, Matplotlib)
- SQL
- Microsoft Excel
- Power BI

## Project Structure:-
- 01_Python – Data cleaning and analysis
- 02_SQL – SQL queries and analysis
- 03_Excel – Excel analysis and dashboard
- 04_PowerBI – Interactive Power BI dashboard
- 05_Dataset – Retail sales dataset

## Key Objectives:-
- Clean and prepare retail sales data
- Analyse monthly sales trends
- Identify top-performing products
- Explore sales performance
- Create interactive dashboards
